📐 Position Sizing Formula

Position Size = MIN[(Portfolio × Risk%) / Stop%, Portfolio / Max Positions]

MIN Risk-Based Position Sizing:

This formula calculates position size using the minimum of two methods: risk-based sizing and portfolio diversification limits. It ensures you don't risk more than your tolerance while maintaining portfolio diversification.

Method 1: (Portfolio × Risk%) / Stop% - Size based on risk tolerance

Method 2: Portfolio / Max Positions - Size based on diversification

The system uses whichever method gives the smaller position size for safety.
