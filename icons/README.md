# Icons Directory

This directory should contain the following PWA icons:

## Required Icons:
- `icon-192.png` - 192x192 PNG icon for PWA manifest
- `icon-512.png` - 512x512 PNG icon for PWA manifest  
- `favicon.ico` - 16x16 and 32x32 ICO favicon

## Icon Design Guidelines:
- Use the TradersMind brand colors (#2196f3 background, white text/symbols)
- Include "TM" text or a calculator/chart symbol
- Ensure icons work at small sizes
- Use simple, recognizable design
- Follow PWA icon best practices

## Tools for Icon Generation:
- Use online favicon generators
- Create using design tools like Figma, Canva, or Adobe Illustrator
- Ensure proper sizing and format compliance

## Temporary Solution:
For testing purposes, you can create simple colored squares with "TM" text as placeholder icons until proper branded icons are designed.
